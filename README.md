# Python-Calculator

# Introduction
A calculator that will be able to do advanced functions, this calculator is not like any regular calculator this calculator can do advanced such as plotting equations on a 2D graph or even doing it in a 3d graph! Not only can this calculator plot 2d and 3d graphs but it is also a scientific calculator with an equation solver that solves basic equations you give it.
